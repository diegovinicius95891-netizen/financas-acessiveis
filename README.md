# Accessible Finances

Programa para organizar receitas e despesas no Windows 10 e 11 de 64 bits, com interface em português, navegação pelo teclado e integração com NVDA.

## Baixar e instalar

[Baixe a versão mais recente](https://github.com/diegovinicius95891-netizen/financas-acessiveis/releases/latest) e abra o arquivo `AccessibleFinances-...-Setup.exe`. O instalador também aparece com o nome `FinancasAcessiveis-...-Setup.exe` para compatibilidade com versões antigas: os dois arquivos são idênticos. Instale somente um deles.

O instalador ainda não possui assinatura digital de editor. O Windows pode mostrar um aviso de editor desconhecido.

## Recursos

- Despesas e receitas com categorias personalizadas e meses expansíveis.
- Relatórios por período em texto e Excel, com uma aba por mês e fórmulas editáveis.
- Manual em texto no menu Ajuda e junto da instalação.
- Navegação por lista ou abas, atalhos, avisos com NVDA e confirmação de saída opcional.
- Gemini opcional, com revisão dos dados antes de autorizar o envio ao Google. Exige chave própria de API.
- Dados locais, cópias de segurança e atualizações confirmadas pelo usuário.

## Manual e suporte

[Leia o manual](Manual-Accessible-Finances.txt). Para relatar problemas, use a aba Issues, sem publicar chaves de API ou informações financeiras pessoais.

Este repositório contém apenas documentação e distribuição do programa pronto. O código do aplicativo é mantido em repositório privado. Os arquivos automáticos que o GitHub chama de “Source code” contêm somente os documentos deste repositório, não o código do aplicativo.
